# AI入門デモ教材（30分・初心者向け）

対象: 無料のGoogleアカウントを持つAI初心者
所要時間: 30分（各デモ約8〜10分）
準備するもの: ブラウザとGoogleアカウントのみ（インストール不要）

## 構成

1. [01_Gemini基本操作.md](01_Gemini基本操作.md) — Gemini(無料)でチャットAIの基本を体験
2. [02_プロンプトの書き方.md](02_プロンプトの書き方.md) — 良い指示・悪い指示の比較で「伝え方」を学ぶ
3. [03_NotebookLM資料要約.md](03_NotebookLM資料要約.md) — 自分の資料をAIに読ませて要約・Q&Aさせる

## デモの進め方（目安）

- 導入（3分）: AIチャットとは何か、無料でできることを説明
- デモ1 Gemini基本操作（8分）: 実演＋受講者に真似してもらう
- デモ2 プロンプトの書き方（8分）: Before/Afterを見せて自分の文章で試す
- デモ3 NotebookLM（8分）: 手元のPDFやメモを読み込ませて要約させる
- まとめ・質疑（3分）
